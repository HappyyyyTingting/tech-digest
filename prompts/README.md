# Prompt 版本管理

每个自动化任务的 prompt 按任务分目录，每个版本一个文件，文件名就是版本号。

约定：

- 文件内容就是可以直接整段粘贴到平台（Grok automations 等）的完整 prompt，不加标题、frontmatter 或代码围栏。
- 版本只增不改：要调整 prompt 时新建 `v2.md`、`v3.md`，不要修改已归档的版本，方便 diff 和回滚。
- 仓库里的文件是版本记录；**实际生效的是平台上的配置**。改完平台后，要同步更新下面的「当前线上版本」。
- 每次更新 prompt 后，顺手把新版本粘贴到平台、跑一次验证，再提交到 git。
